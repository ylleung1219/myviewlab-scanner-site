Privacy Policy

Last updated: November 11, 2026

This Privacy Policy explains how MyViewLab Scanner Drive accesses, uses, stores, and manages Google Drive data.

MyViewLab Scanner Drive is a personal stock market research utility designed to generate technical screening reports and upload CSV files to a user-selected Google Drive folder.

1. Information Accessed

The application requests the following Google OAuth permission:

Google Drive API - drive.file

This permission allows the application to access, create, and modify specific Google Drive files created by or explicitly authorized for use with the application.

The application uses Google Picker during initial setup to allow the user to select a Google Drive folder.

The application does not request unrestricted access to all files in the user's Google Drive.

2. How Information Is Used

Google Drive access is used only to support the application's file management features.

These features include:

  • Uploading CSV reports generated by the stock market scanner.
  • Updating previously uploaded CSV reports.
  • Accessing metadata required to identify the selected folder and uploaded files.

Google Drive data is not used for advertising, profiling, or unrelated purposes.

3. Data Storage and Security

Google OAuth access and refresh tokens are stored locally on the authorized computer.

The application stores OAuth tokens in:

drive_token_limited.json

The application also stores the selected Google Drive folder ID and identifiers of uploaded files in:

drive_upload_settings.json

These files are used to maintain authorization and support automatic updates to existing CSV reports.

The application does not encrypt these local configuration files. Users should protect their computers and restrict unauthorized access to these files.

OAuth tokens are not published on the MyViewLab website.

4. Data Sharing and Third-Party Services

The application does not sell Google user data or use it for advertising.

CSV reports uploaded to Google Drive remain subject to the sharing permissions configured by the Google Drive folder owner.

Users who have access to the selected shared folder may be able to view or download uploaded CSV reports.

The stock scanner may also send generated market signals and summary information to a configured Discord webhook when Discord notifications are enabled.

These Discord notifications are generated from stock market analysis. The Google Drive integration does not retrieve private Google Drive file contents for transmission to Discord.

5. Data Retention and Deletion

Uploaded CSV reports remain in the selected Google Drive folder until deleted by an authorized user.

The application does not automatically delete uploaded CSV reports.

Users may delete uploaded files directly through Google Drive.

Users may also manually remove locally stored OAuth tokens and application configuration files from their computers.

6. Revoking Google Access

Users can revoke the application's access to Google Drive at any time through their Google Account settings:

Google Account Connections

Revoking authorization prevents further authorized Google Drive API operations.

Revoking authorization does not automatically delete previously uploaded CSV files or locally stored application configuration files.

7. Google API Limited Use

MyViewLab Scanner Drive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to This Privacy Policy

This Privacy Policy may be updated to reflect changes to the application's functionality or data handling practices.

Any updates will be published on this page with a revised effective date.
